# Llegó el "Spec-Driven Development" (Últimos 6 meses)
<!-- background: context.png -->
<!-- hide-from: 1 -->
> *Spec Driven Development propone, en esencia que la especificación preceda y guíe al código. 

- Escribir primero una especificación clara
- Usar esa especificación como fuente tanto para humanos como para agentes de IA. 
- Generar código a partir de la spec, no de prompts improvisados.

> *Damos el salto definitivo. creamos un Spec (Especificación) para la IA. hacemos que los .md tengan un formato comun.

<!-- reveal -->
```
# Spec: Conversor de Notas a Presentaciones

## Core Stack
- Frontend: HTML5 + Tailwind CSS + JS Nativo (Sin frameworks).

## Reglas de Negocio
- Modo Editor: Entrada de texto Markdown.
- Modo Presentación: Si detecta `---`, activa el visor de slides.
- Navegación: Flechas del teclado e histórico en la URL (`#slide-1`).

## UI/UX
- Temas: Conmutable entre Modo Claro y Modo Oscuro (por defecto).
- Bloques de código con resaltado de sintaxis limpio.
...
```
